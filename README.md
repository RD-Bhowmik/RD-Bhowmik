A comprehensive financial management web application for international students with real-time currency conversion across 19+ currencies.

**Tech Stack:** Python, Flask, PostgreSQL, Bootstrap 5, JavaScript  
**Key Features:**
- Real-time currency conversion with ExchangeRate API integration
- Secure user authentication with bcrypt
- Multi-currency financial tracking and analytics
- Responsive mobile-first design
- Cloud deployment on Vercel

**Live Demo:** [https://finance-trackerforstudents.vercel.app/sources](https://planning-phi.vercel.app)

### 📊 [Disease Profile Prediction](https://github.com/RD-Bhowmik/cse437-project)
Machine learning system predicting future disease profiles for 204 countries based on 30 years of mortality data.

**Tech Stack:** Python, Pandas, Scikit-learn, Matplotlib, Jupyter Notebook  
**Key Features:**
- Random Forest classification with 63.4% accuracy
- Processed 1.47 billion death records
- Feature engineering with 8 temporal features
- Comprehensive epidemiological analysis
- Statistical visualization and reporting
